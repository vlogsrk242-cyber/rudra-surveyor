# RUDR SURVEYOR

Gujarati + English land measurement starter project.

Included:
1. RUDR SURVEYOR branding/logo
2. App Icon / Splash / Home asset base
3. Gujarati + English UI
4. Land Measurement
5. Area Calculator
6. Unit Converter section
7. Surveyor Knowledge
8. Survey Report form
9. Customer Care: 8487847474
10. Codemagic release workflow

Note:
The Codemagic workflow expects an Android keystore named `rudr_keystore` to be configured in Codemagic.
